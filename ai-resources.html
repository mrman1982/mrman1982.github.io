AI resources for safer use of public, private and offline tools

General AI Assistants & Research Tools

  • Google Gemini — chat, multimodal understanding, and Docs/Slides help. Visit Google Gemini

    Explore brainstorming, rewriting and supported image tools. Workspace features depend on the account and plan. Check the relevant data policies before using business information.

  • OpenAI ChatGPT — versatile chat for writing, code, and Q&A. Visit ChatGPT

    A general assistant for drafting, questions and coding. Do not assume a public chat account is suitable for confidential information. Review the account's data controls first.

  • Microsoft Copilot — Microsoft’s assistant with Bing search. Visit Microsoft Copilot

    Features and Microsoft 365 integrations vary by product and subscription. Review the specific account's data controls and terms before using business information.

  • Anthropic Claude — a general assistant for reading, drafting and questions. Visit Claude

    Consider for document summaries and drafting, with human review. Check the relevant account's terms and data handling before sharing business documents.

  • Perplexity — research assistant with citations. Visit Perplexity

    Research with source links. Open and check the cited material before relying on an answer.

Image & Media Creation

  • Google Gemini (Images) — image generation and understanding. Explore Gemini image tools

    Create images from prompts and understand images (availability varies by region/account).

  • OpenAI ChatGPT (Images) — image generation via integrated models. Explore ChatGPT image tools

    Generate and iterate on images from natural language prompts alongside chat.

  • Adobe Firefly — generative images/text effects, integrated with Creative Cloud. Explore Adobe Firefly

    Explore image generation and editing for creative work. Review commercial-use terms and check generated assets before publication.

  • Midjourney — image generation through its website and Discord. Explore Midjourney

    Explore visual concepts and image variations. Check the current plan's usage rights and visibility settings before sharing confidential prompts or reference images.

  • Stable Diffusion — open‑source image models (local or cloud). Explore Stable Diffusion

    Local image workflows are possible with suitable models, hardware and software. Check the chosen model's licence and any external connections.

  • ComfyUI — node‑based workflows for image pipelines. Explore ComfyUI image workflows

    Visual graph editor to build and automate image generation/fine‑tuning workflows.

Local & Offline Options

  • ComfyUI (Local) — build private, reproducible image pipelines. Explore local ComfyUI setup

    Run suitable workflows locally. Review the selected nodes, models and external connections before using sensitive material.

  • Ollama — run language models locally. Explore Ollama

    Try a local assistant on your own machine or server. Model choice, configuration and connected services affect where data is processed.

  • LM Studio — desktop app to run local models. Explore LM Studio

    A desktop interface for trying suitable local models. Review model requirements, settings and licences before business use.

  • Stable Diffusion (Local) — image generation on‑prem. Explore Stable Diffusion WebUI

    The linked project provides a web interface for local image generation. Check installation requirements, extensions and model licences before use.

  • FLUX (local models) — an image model family. Explore FLUX models

    Suitable variants can run locally with the right setup. Check the selected model card, hardware requirements and licence.

  • Wan2.2 — a video-generation model family. Explore the Wan2.2 project

    The official project includes text-to-video and image-to-video workflows. Review the chosen model's requirements and licence before installation or commercial use.

Need help choosing or deploying? We specialise in private and offline AI that can be designed to keep sensitive data on your own hardware or controlled infrastructure. A local tool is not automatically an offline workflow. Review connected services, extensions and settings before treating a setup as private.

Tips for Responsible Use

  • Keep sensitive or regulated data out of public tools. Review any proposed offline or business account setup before sharing it.
  • Review licensing and usage rights for generated media, especially in commercial settings.
  • Validate facts with cited sources and treat outputs as drafts requiring human review.
